# Issue Contract Template (global minimum)

```text
Intent:
Goal:
Authority:
Scope:
Constraints:
Non-goals:
Dependencies:
Acceptance Criteria:
Required Evidence:
Exit:
```

Optional:

```text
Required execution skill: evidence-backed-delivery
Owner decision / human gate:
Related parent / meta issue:
Known PR / branch / worktree:
```

Rules:

- Open issue = work candidate, not implement authorization.
- Missing/contradictory core fields → `HOLD_ISSUE_CONTRACT_INCOMPLETE`.
